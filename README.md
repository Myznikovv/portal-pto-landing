# Лендинг ПТО

Статичная страница без сборки: `index.html`, `site.css`, `main.js`; дизайн-система в `design/`.

Запуск локально: `python3 -m http.server 8765` в этой папке и открыть `http://127.0.0.1:8765/index.html`.
Проверка токенов и контраста: `node design/check-tokens.cjs` (должна проходить перед любой правкой стилей).

## Структура (листы)
1 первый экран · 2 где теряется время · 3 «акт собирается» (закреплённая сцена) · 4 комплект ИД · 5 портал (скриншоты) · 6 дилерам · 7 заявка.
